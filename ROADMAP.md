# Roadmap

Potential future improvements:

- hardware-in-the-loop replay from sanitized Vicon logs;
- typed adapter for additional Sphero backends;
- formal stale-frame watchdog metrics;
- automatic breakaway-characterisation utility;
- trajectory library beyond square/circle paths;
- richer offline log visualisation;
- deterministic controller replay tests;
- ROS 2 adapter while keeping the core controller middleware-independent.
