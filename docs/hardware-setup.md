# Hardware setup

## Minimum equipment

- one or more compatible Sphero robots;
- chariot/wheeled carrier if reproducing loaded behaviour;
- Bluetooth-capable host computer;
- Vicon system with rigid bodies attached to each chariot;
- physically clear operating area.

## Before motion

1. Charge every robot.
2. Confirm the chariot wheels move freely and are aligned.
3. Verify Vicon labels correspond to physical robots.
4. Confirm the operating-area bounds.
5. Keep a clear path to the robots and an operator ready to stop the process.
6. Begin with one robot and a low speed.

Do not use historical speed or calibration values blindly after changing robot, chariot, wheel alignment, floor surface, battery condition or marker geometry.
