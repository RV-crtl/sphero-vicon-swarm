# Sphero + Vicon Swarm Control

This site documents a public toolkit for external-motion-capture control of Sphero chariots. Start with the software-only workflow, then progress through one robot, Vicon-only tracking, heading calibration, closed-loop motion and finally multi-robot trajectory control.

The project keeps hardware-specific identifiers outside source control and includes automated privacy, quality and security checks suitable for a public GitHub repository.
