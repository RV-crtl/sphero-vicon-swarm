# v1.0.0 — Initial public release

Released: 16 October 2026

Version 1.0.0 is the first stable public release of **Sphero + Vicon Swarm Control**, a reusable Python toolkit for Vicon-referenced control of Sphero BOLT/BOLT+ chariots.

## Highlights

- staged progression from one robot to multiple robots, Vicon-only tracking, calibration and closed-loop control;
- per-robot displacement calibration between the Sphero command frame and Vicon world frame;
- centralised three-chariot trajectory and formation-control reference implementation;
- simulator and dry-run path that require no hardware;
- configurable workspace, robot identifiers, Vicon rigid bodies and control settings;
- boundary recovery, collision-repulsion safeguards, logging and digital-twin support;
- public `spherov2` adapter with Vicon DataStream SDK integration kept behind reusable interfaces;
- tests, strict typing, linting, formatting, packaging checks and cross-platform CI;
- privacy scanning, Gitleaks, CodeQL, dependency auditing and OpenSSF Scorecard analysis;
- GitHub Pages documentation and reproducible release artifacts.

## Supported environment

The automated test matrix covers:

- Python 3.11, 3.12 and 3.13;
- Ubuntu;
- Windows.

The software-only simulator and unit-test path is hardware-independent.

Physical operation additionally depends on compatible Sphero hardware, Bluetooth support and—when Vicon tracking is used—the vendor Vicon DataStream SDK Python bindings.

## Recommended first run

Clone the tagged release, create an isolated Python environment, install the development dependencies and run the software-only checks before connecting hardware:

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/RV-crtl/sphero-vicon-swarm.git
cd sphero-vicon-swarm
python -m venv .venv
python -m pip install -e ".[dev,docs]"
python -m sphero_vicon_swarm doctor
python -m sphero_vicon_swarm simulate --seconds 8
pytest
```

For the public BLE backend:

```bash
python -m pip install -e ".[sphero]"
```

Install the Vicon DataStream SDK separately when using Vicon hardware.

## Safety and limitations

This project can command physical robots. Begin at low speed, verify robot-to-rigid-body mappings, keep the operating area clear and maintain an immediate stop path.

BLE is not hard real-time. Mechanical friction, battery state, wheel alignment, mounting geometry and Vicon occlusion can materially change behaviour. Collision and boundary logic are safeguards, not safety certification.

The reference implementation is intended for research, prototyping and education. It is not a safety-certified motion-control product.

## Privacy

Public configuration and examples contain placeholders only. Real network addresses, robot identifiers, personal paths and unsanitized experimental logs should remain local and untracked.
